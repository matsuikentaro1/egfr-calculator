# eGFR計算アプリ

腎機能の指標であるeGFR（推算糸球体濾過量）を計算するためのシンプルなウェブアプリケーションです。

## 機能

- 性別、年齢、血清クレアチニン値（Cre）を入力してeGFRを計算
- 日本腎臓学会のeGFR推定式に準拠
- CKDステージの自動判定
- スマートフォン対応のレスポンシブデザイン
- 大きめの文字サイズで見やすいUI

## 技術情報

このアプリは以下の技術を使用しています：
- HTML5
- JavaScript
- Tailwind CSS

## 使い方

1. 性別を選択（男性/女性）
2. 年齢を入力（0〜120歳）
3. 血清クレアチニン値を入力（単位: mg/dL）
4. 「計算する」ボタンをクリック
5. 結果画面でeGFR値とCKDステージを確認

## 計算式

日本腎臓学会によるeGFR推定式（成人用）：

```
eGFR = 194 × Cr⁻¹.⁰⁹⁴ × 年齢⁻⁰.²⁸⁷ ×（0.739 if 女性）
```

## 注意事項

- このアプリは医療アドバイスを提供するものではありません
- 正確な診断には医師の診察が必要です
- 入力データはサーバーに保存されません

## ローカルで動かす

`index.html` をブラウザで開くだけで動きます。ビルドもインストールも不要です。
